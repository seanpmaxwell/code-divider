code-divider - format separator / header comment markers

Usage:
  code-divider [options] [paths...]

Arguments:
  paths              Files or directories to process (default: current
                      directory). Directories are walked recursively, skipping
                      node_modules and dotfiles.

Options:
  -i, --init <value>    Initialize with the given value.
  -h, --help            Show this help.
  -d, --dry-run         Show what would change without writing any files.
  -p, --path <value>    Path to operate on.
  -c, --config <value>  Config file to use.
  -v, --version         Show the version.

Markers (rewritten in place, centered and padded to the character limit):
  // @reg Label    Region  -> a 3-line boxed header block.
  // @sec Label    Section -> a single centered header line.

Supported files: JavaScript, Java, CSS, C, C++, Go, Rust, PHP, Ruby, SQL
(and any others added via code-divider.config.json).
